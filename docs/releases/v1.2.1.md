# Task Manager 1.2.1

This maintenance release combines the reviewed fixes from pull requests #3–#29, with consistent version metadata and a release process that publishes the verified Windows production build.

## Resource reporting

- Report GPU utilization using the busiest actual engine, including correct shared-engine totals for application groups (#3).
- Keep network rates coherent after Windows API failures and use the successful counter sample's timestamp (#9).
- Keep application process groups within one user session (#12) and sort Base priority by its scheduler value (#13).
- Show memory transfer speed in MT/s (#15).
- Sample CPU usage across all processor groups and reset baselines when the topology changes (#17).
- Refresh cached GPU and disk identities on explicit refresh, including changed or replaced hardware (#24).

## Process, service, and startup actions

- Correct Run new task and startup-command parsing for spaces, tabs, quoted paths, environment variables, and inferred executable extensions (#5).
- Capture owned process/session targets before modal dialogs, resolve expanded window rows to their process, and retain complete descendant-first process trees (#6).
- Preserve preexisting temporary files when dump creation fails (#7).
- Stop startup registry scans after permanent enumeration errors while continuing past oversized entries (#8).
- Request only the access rights each service action needs (#10).
- Restore saved priority when Efficiency mode has been cleared externally (#11).
- Preserve domain-qualified user identities and verify session identity before disconnecting or signing off (#22).

## Windows interface

- Keep busy headers, tabs, and Performance navigation readable in High Contrast (#4).
- Correct ownership of the row image list (#14) and preserve table layout, selection, scrolling, and scaled icons when DPI changes (#21).
- Restore keyboard focus when leaving Performance (#18).
- Keep the tray meter current while minimized and restore it after Explorer restarts (#19).
- Keep Name first when table columns are reordered (#20).
- Preserve the viewport during automatic numeric refreshes (#26).
- Keep dense CPU and GPU graphs visible in narrow windows, with an explicit overall-CPU fallback when individual graphs cannot fit (#28).
- Skip category headings during native keyboard navigation (#29).

## History and diagnostics

- Persist application history with explicit UTF-8 encoding and escaped metadata fields (#16).
- Escape diagnostic errors and sorting failures as valid JSON (#23).
- Reject stale, missing, malformed, or unsuccessful benchmark reports (#25).
- Decode UTF-8 error messages consistently in Windows dialogs, including Run new task (#27 and integration cleanup).

## Download

Download **TaskManager.exe** and **SHA256SUMS.txt** from this release. The standalone executable requires Windows 10 or Windows 11 x64 and administrator approval. It is unsigned and requires no .NET runtime. Replacement of Windows Task Manager remains optional; see the README for installation, updates, and recovery instructions.

## Verification and limits

The release job publishes only the production executable built from the exact merged commit after Windows verification succeeds. That workflow builds production and optimized diagnostics with MSVC warnings treated as errors, runs all ten CTest cases, checks production manifest and diagnostic exclusion, runs the component benchmark and all 21 benchmark-suite scenarios, and validates benchmark-report and release-publication guards. Executable, manifest, and project versions must agree, and the uploaded executable must match its SHA-256 checksum.

Synthetic fixtures cover multi-GPU accounting, large process trees, multiple processor groups, dense CPU graphs, High Contrast, DPI, and keyboard behavior. They do not establish physical multi-GPU or 128-CPU hardware validation, complete Windows 11 feature parity, or universal performance improvements. Existing feature differences and OS restrictions remain documented in README and docs/PARITY.md.
